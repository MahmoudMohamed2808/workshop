# تشغيل opencode بترتيب على مشروع الورشة

## 1. حط الملفات اللي عملناها في مجلد `docs/`

جوه مشروع اللارافيل بتاعك، اعمل المجلد ده وحط فيه كل الملفات:

```
your-laravel-project/
├── docs/
│   ├── 01-features.md              (workshop-system-features.md)
│   ├── 02-database-schema.md       (workshop-database-schema.md)
│   ├── 03-filament-resources.md    (filament-resources-structure.md)
│   ├── 04-models-services.md       (models-services-provider.md)
│   └── 05-arabic-localization.md   (arabic-localization-guide.md)
├── AGENTS.md
├── opencode.json
└── ... (باقي ملفات اللارافيل)
```

رقّمت الملفات (01, 02, 03...) عشان الترتيب يبقى واضح بصريًا حتى لو فتحت المجلد بعينك، مش بس للـ AI.

---

## 2. اعمل `AGENTS.md` في روت المشروع

جرب الأول تكتب في التيرمنال:
```bash
opencode
/init
```
ده هيحلل مشروعك (composer.json, artisan, إلخ) ويعمل `AGENTS.md` أساسي. بعد كده افتحه وضيفله القسم ده فوق أو تحت (حسب ما يظبط):

```markdown
# Workshop Repair System — Agent Instructions

## Stack
- Laravel 13, React Starter Kit (Inertia + Fortify), Filament v5
- spatie/laravel-medialibrary, spatie/laravel-tags, spatie/laravel-permission (+Filament Shield), spatie/laravel-activitylog

## Planning Documents (READ BEFORE CODING)
كل قرارات المعمارية والتصميم موجودة في مجلد docs/. اقرأها بالترتيب ده قبل أي تنفيذ:
1. docs/01-features.md — الفيتشرز الكاملة مقسمة Phase 1/2/3
2. docs/02-database-schema.md — كل الجداول + أوامر artisan make:model -mfs
3. docs/03-filament-resources.md — شجرة الـ Resources + Relation Managers + Custom Actions
4. docs/04-models-services.md — العلاقات بين الموديلز + طبقة الـ Services + الـ Service Provider والـ Facades
5. docs/05-arabic-localization.md — استراتيجية التعريب (لازم تتطبق من أول Resource بيتعمل، مش آخر حاجة)

## Execution Rules
- نفّذ حاجة واحدة في المرة الواحدة (migration واحد، موديل واحد، Resource واحد) ومتابعش للي بعده غير لو قلتلك "كمل".
- بعد كل خطوة، شغّل `php artisan migrate` أو `php artisan test` (لو فيه) للتأكد إن مفيش كسر.
- كل نص يتعرض في الواجهة لازم يمر على `__()` من أول لحظة (مش تعريب لاحق) — اتبع docs/05-arabic-localization.md.
- استخدم أسماء الموديلز والجداول بالظبط زي ما هي في docs/02-database-schema.md (لاحظ: DeviceModel مش Model).
- الـ Services تتسجل في WorkshopServiceProvider كـ singleton، والـ Facades الخمسة بس المذكورة في docs/04 (متعملش facade لكل حاجة).
```

## 3. خلي opencode يحمّل الملفات دي تلقائيًا في كل Session

عدّل `opencode.json` في روت المشروع:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "instructions": [
    "docs/01-features.md",
    "docs/02-database-schema.md",
    "docs/03-filament-resources.md",
    "docs/04-models-services.md",
    "docs/05-arabic-localization.md"
  ]
}
```

كده كل الملفات دي بتتحمل كـ context أساسي مع الـ AGENTS.md في أول أي session، من غير ما تحتاج تكتب `@docs/...` كل مرة.

> ملاحظة: لو حسيت إن الـ context بقى تقيل أوي (كل الملفات دي مع بعض)، شيلها من `instructions` واستخدم الإشارة اليدوية `@docs/02-database-schema.md` في البرومبت وقت ما تحتاجه بس — ده بيوفر توكنز.

## 4. خطة التنفيذ بالترتيب (استخدمها كبرومبتات منفصلة)

الأفضل متطلبش من opencode "ابني المشروع كله" في برومبت واحد — قسّمها كده:

### الخطوة 1 — الـ Migrations
```
اقرأ docs/02-database-schema.md ونفّذ الجداول بالترتيب اللي فيه، جدول جدول.
ابدأ بس بأول 3 جداول (customers, device_types, brands) وأنا هراجعها قبل ما تكمل.
```

### الخطوة 2 — باقي الـ Migrations + الـ Models والعلاقات
```
كمل باقي الجداول من docs/02، وبعدين اعمل العلاقات (relationships) في كل موديل
زي ما هو موصوف في docs/04-models-services.md.
```

### الخطوة 3 — الـ Service Provider والـ Services
```
اعمل الـ Services المذكورة في docs/04-models-services.md واحدة واحدة،
وسجّلها في WorkshopServiceProvider، واعمل الـ 5 Facades بس المذكورين.
ابدأ بـ RepairOrderWorkflowService الأول.
```

### الخطوة 4 — Filament Resources (واحد واحد)
```
اعمل CustomerResource بس دلوقتي حسب docs/03-filament-resources.md
(الحقول، الـ Relation Managers، الـ Custom Actions المذكورة).
كل نص فيه لازم يستخدم __() حسب docs/05-arabic-localization.md.
```
وكرر نفس البرومبت لكل Resource لوحده (DeviceTypeResource, BrandResource... إلخ) — متطلبش كل الـ 12 Resource مرة واحدة.

### الخطوة 5 — التعريب الشامل (مراجعة أخيرة)
```
راجع كل الـ Resources والـ Services اللي اتعملت وتأكد إن كل نص معروض للمستخدم
بيمر على __() ومفيش نص عربي أو إنجليزي inline، حسب docs/05-arabic-localization.md.
```

## 5. استخدم Plan Mode قبل أي تنفيذ فعلي

في opencode، دوس `Tab` عشان تدخل **Plan Mode** — ده بيخلي الـ AI يقترحلك الخطوات قبل ما يلمس أي كود فعليًا. مفيد جدًا مع كل خطوة من الخطوات فوق، خصوصًا الـ Migrations والـ Resources المعقدة زي RepairOrderResource.

سير العمل المقترح لكل خطوة:
1. `Tab` (Plan Mode) → اكتب البرومبت → راجع الخطة المقترحة
2. لو تمام، ارجع لـ Normal Mode ونفّذ
3. راجع الـ diff (`opencode` بيوريك التغييرات)
4. `git commit` بعد كل خطوة ناجحة — كده لو حاجة غلط تقدر ترجع بسهولة

## الخلاصة

| الملف | دوره |
|---|---|
| `AGENTS.md` | القواعد العامة + رابط للـ docs |
| `opencode.json` | يحمّل الـ docs تلقائيًا كـ context |
| `docs/01` إلى `docs/05` | مصدر الحقيقة الوحيد للقرارات المعمارية |
| برومبتات مقسّمة خطوة بخطوة | تمنع الـ AI من عمل كل حاجة مرة واحدة بشكل عشوائي |
| Plan Mode + git commit بعد كل خطوة | شبكة أمان لو حاجة غلطت |
